# ⚡ QR-Relay v2.0 — 动态二维码低延迟中继系统

**QR-Relay** 是一款 100% 纯前端实现的动态二维码低延迟中继工具。针对高频刷新（6–8 秒）的课堂动态签到二维码，系统采用**“边缘端侧毫秒级解码 + 百字节级 MQTT over WSS 实时信令转发 + 远程端侧自适应响应”**架构，端到端理论延迟 **< 0.4 秒**，彻底解决传统“拍照发微信”链路延迟高、摩尔纹反光及过期失效的问题。

---

## ✨ 核心特性

* **零服务器运维 & 单文件交付**：所有逻辑收敛于单个 `index.html`，无需后端与数据库，可直接托管于 GitHub Pages、腾讯云 EdgeOne Pages 或 Cloudflare Pages（自动获得 HTTPS）。
* **教室采集端（Sender）**：
  * **双模变焦控制**：优先调用后置摄像头硬件 `zoom` 无损变焦，不支持时自动降级为 1.0x–3.0x 数字 ROI 中心高清裁剪放大。
  * **双引擎高速解码**：优先调用浏览器原生硬件加速 `BarcodeDetector`，异常或不支持时无缝降级至 `jsQR`（150ms 抽帧 + 严格去重）。
  * **一扫双得（单发模式）**：可选开启「广播首帧后自动跳转为自己签到」，通过 `QoS 1` 确认消息发出后自动拉起签到页。
* **远程接收端（Receiver）**：
  * **微信内零点击自动直跳**：支持直接在微信内置浏览器打开，开启自动跳转后收到有效链接瞬间无缝继承微信登录态完成签到。
  * **防打断高保真重绘**：锁定纯白底与 `24px` 静默区输出标准 Base64 `<img>`（兼容微信长按识别），内置**触摸冻结（Touch-Freeze）**保护，手指按住识别期间锁定画面不刷新。
  * **单调时钟新鲜度预警**：基于 `performance.now()` 驱动 `100ms` 精度计时条，绿/黄/红三色动态提示二维码剩余有效窗口。

## 🚀 三种实战使用姿势

1. **双设备黄金组合（最稳妥）**
   * **教室端**：在系统浏览器（Chrome / Safari / Edge）打开网页，输入房间口令并进入「教室端」，拉动变焦滑块对准大屏。
   * **远程端**：在电脑或平板打开网页，输入相同口令进入「远程端」（关闭自动跳转），手机微信「扫一扫」在绿色计时区间内扫码即可。
2. **单手机微信极速闭环（远程仅需一部手机）**
   * 远程同学直接将链接发至微信「文件传输助手」点开，输入相同口令进入「远程端」，开启**「收到有效链接后自动跳转」**，教室端扫到码后 `0.4s` 内自动跳转签到。
3. **教室前排一扫双得**
   * 教室同学在微信内打开网页进入「教室端」，勾选**「广播首帧后自动跳转为自己签到」**，扫到大屏首帧确认发出后自动跳往签到页。

## 🛠️ 技术栈与依赖

* **信令中继**：`mqtt.js` (MQTT over WSS, 公共节点 EMQX / HiveMQ)
* **端侧解码**：原生 `BarcodeDetector` API + `jsQR`
* **端侧重绘**：`qrcodejs`
* **原生能力**：`MediaDevices.getUserMedia`、`Screen Wake Lock API`、`Vibration API`、`performance.now()`
